## Home

Users can browse most of the view pages without being logged in. For a better experience, users are encouraged to browse the application while logged in. Users can also switch the website language to their preferred language.

*Figure- 1 Home page header with Login, Sign Up, and language switcher*

### How to Sign Up or Create an Account

1. On the top-right side of the home page, there are two buttons:
   * **Login**
   * **Sign Up**
2. If the user already has an account, they do not need to sign up again.
3. To create a new account, click **Sign Up**.
4. Fill in the registration form with the following details:
   * **First Name:** Enter the user's first name.
   * **Last Name:** Enter the user's last name.
   * **Email:** Enter a unique email address.
   * **Password:** Enter a password.
5. Submit the form.
6. If the provided email address does not conflict with another user's email, the registration will be completed successfully.
7. In some cases, the user may need to verify their email address. This feature is controlled by the admin.

*Figure- 2 Registration form*

### How to Log In to the Application

1. Click the **Login** button.
2. Enter the valid email address and password used during account creation.
3. Submit the login form to access the account.

### How to Get a Course List

1. Users can browse different course lists, such as:
   * **Category-based course list**
   * **Top Courses**
   * **Top 10 Latest Courses**
2. To find courses from a specific category, select the required category from the **Category** menu at the top.
3. For example, to view Web Development courses, select **Web Development** from the category menu.
4. Under the banner image, users can view horizontal lists for **Top Courses** and **Top 10 Latest Courses**.

*Figure- 3 Top Courses and Top 10 Latest Courses sections*

### How to Search for a Course

1. Use the **Search** field.
2. Enter the course title.
3. The system will display courses that match the search keyword.

*Figure- 4 Course search result page*

### Wishlisting Courses

1. Users can add courses to their wishlist.
2. Wishlist functionality is available only when the user is logged in.

*Figure- 5 My Wishlist page*

### Adding to Cart

1. Users can add courses to their cart without being logged in.
2. Login is required only when the user wants to proceed to checkout.

## Course Details

### What Is Inside Course Details?

When a user clicks a course link, the system opens the **Course Details** page. This page displays all important information about the selected course, including:

* **Course title**
* **Instructor details**
* **Rating and reviews**
* **Learning outcomes**
* **Prerequisites**
* **Lesson list**
* **Total course duration**
* **Video overview**
* **Related courses** from the same category and subcategory

Users can also add the course to their cart or directly purchase it from this page.

*Figure- 7 Sample course details page*

## Course Comparison

### What Is Course Comparison and How to Use It?

1. Users may have multiple course choices before making a purchase.
2. The **Course Comparison** feature helps users make a better decision.
3. Users can compare up to **3 courses** side by side.
4. The comparison page displays course information such as:
   * Price
   * Language
   * Last update date
   * Level
   * Short description
   * Total lessons
   * Total duration
   * Number of reviews
   * Total enrollment
   * Average rating
   * Requirements

*Figure- 8 Course comparison page*

## Cart

### What Is Inside My Cart?

1. Users do not need to be logged in to add courses to their cart.
2. If users want to checkout, they must log in.
3. The cart page displays all courses added to the cart.
4. Users can remove courses from the cart.
5. The total amount is calculated based on the selected courses.

## My Courses

### What Is Inside My Courses?

1. When a user purchases a course, it is added to the **My Courses** page.
2. Users can access this page only when they are logged in.
3. The **My Courses** page contains all purchased courses.
4. From this page, users can:
   * Rate purchased courses
   * View course details
   * Start learning
   * Search for a specific purchased course
5. If the user is logged in, the profile image appears on the top-right side of the header.
6. Hovering over the profile image displays several options, including **My Courses**.

## Become an Instructor

### How to Become an Instructor

By default, registered users can access the website, browse all courses, manage their profile, send messages, view purchased courses, use the wishlist, and use the cart.

If a user wants to create and publish courses, they must become an instructor.

1. Click the **Instructor** menu from the top navigation.
2. If the **Instructor** button is not visible on the frontend top bar, this means the admin has disabled the public instructor option.
3. If the public instructor option is enabled, click the **Instructor** button.
4. The instructor application form will appear.
5. Fill in the form and submit it for admin verification.
6. Attach any required documents while submitting the form.
7. Once the request is approved, instructor options become available, such as:
   * **Dashboard**
   * **Course Manager**
   * **Sales Report**
   * **Payout Report**
   * **Payout Settings**

*Figure- 14 Instructor application form*  
*Figure- 15 Instructor dashboard after approval*

### How to Create Courses as an Instructor

Creating a course as an instructor is almost similar to creating a course as an admin. The main differences are:

* The admin must approve the instructor's course.
* The instructor can save the course as **Drafted** before publishing it.

## Sales Report

### What Is the Sales Report in the Instructor Panel?

The **Sales Report** shows details of purchase histories for the instructor's courses. Instructors can see:

* Who bought their courses
* When the courses were purchased
* How much revenue they earned per purchase

*Figure- 16 Instructor sales report page*

### What Is the Course Commission for Instructors?

If a course created by an instructor is purchased, the instructor receives a commission from that purchase. The commission percentage is set by the admin.

---

## Payout Report

### What Is a Payout Report?

After every successful course purchase, the instructor receives a predefined portion of the paid amount. Instructors can view payment information in the **Sales Report**.

If an instructor wants to withdraw an amount, they can send a payout request to the admin. The **Payout Report** displays both requested payouts and processed payouts raised by the instructor.

*Figure- 17 Instructor payout report page*

### Payout Request Rule

1. An instructor can request only one payout at a time.
2. If a payout request status is **Pending**, the instructor cannot raise another payout request.
3. If the instructor deletes the existing pending request, they can raise another request.
